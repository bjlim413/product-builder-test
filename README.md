# STARK CHECKLIST

아이언맨(J.A.R.V.I.S.) 스타일의 체크리스트 웹앱입니다. 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 화면 구성
1. **서재** – 큰 주제를 책 모양으로 보여줍니다. 책 추가·수정(제목/설명/아이콘/표지 색)·삭제.
2. **목차** – 책을 선택하면 목차와 목차별 진행도, 책 전체 진행도(아크 리액터 링)를 보여줍니다. 목차 추가·수정·삭제.
3. **체크리스트** – 목차를 선택하면 체크박스 목록과 진행도를 보여줍니다.
   - 항목 추가·수정·삭제, 체크 모두 해제
   - **💡 이럴 때 사용하세요**: 이 체크리스트를 언제 쓰면 좋은지 설명. 추가·수정·삭제 가능

데이터는 브라우저 `localStorage`에 저장됩니다.
